# Site fidelity restoration

The visual reference is the live site at https://zimoluo.me, with original source at commit `0e9f7a81`. The October 10, 2026 review compared real pages at 1440 × 1000 and 390 × 844 in Chrome. The scope is the site's authored composition, typography, materials, and motion. Theme Studio keeps its tabs; reproducing its original editor is not the objective.

## Findings and repairs

- Fresh page selections had collapsed onto Home. Whiteout, Blog, Photos, Projects, About, Velvet, Penumbra, Cherry, Unity, and Christmas now retain their original route identities. The theme picker follows the original curated sequence. Explicit saved choices take precedence, including distinct Notebook and Studio choices. Unknown legacy page keys cannot overwrite Home.
- Tailwind v4 font variables were defined above the element that supplied the Next font variables. All font variables now live on the root element, and the theme aliases are inline. The original Inter interface font, Lora blog reading font, and Roboto Mono code font resolve consistently.
- Migrated marks used browser color for an unauthored outline, filled unauthored split regions with text color, and treated an SVG angle as a CSS angle. Default outlines now use primary text, a single authored gradient repeats across all three regions, and legacy gradient angles rotate by 90 degrees on import. Registry marks and generated artwork have the same conversion. Native v11 gradients retain CSS angle semantics.
- Undefined transform variables invalidated cog motion and photo drift. Project cog rotation no longer depends on Tailwind's transform internals; the floating code travels independently of the cog orbit. The original placement, durations, color, and density guide these repairs. Click-to-spin, loading, menu expansion, and Eventide transforms have valid defaults. Pausing motion retains the authored Blog, Photos, and Projects motifs instead of removing their core artwork.
- The shared Three camera had retained forward orientation instead of looking toward the origin. Restoring that orientation brings Whiteout's wave plane back into the original framing. Its square render view, palette, noise settings, and one-context lease remain in use.
- Shadow geometry now follows the original directional spread and blur. Theme tinting and the later main branch's surface highlights remain in use.
- Project tiles again form six columns at the comparison desktop width. Album uses round-robin item distribution and the original 288/168 pixel desktop/mobile column sizes instead of filling columns sequentially. Blog covers retain their own aspect ratios, and tags regain their saturated material and hover response.
- Native reading dialogs no longer use an opaque shade backdrop or the dimming material as the content panel. A translucent scrim, widget reading material, themed text, spacious project image/text split, and viewport close controls restore the reading composition. Blog typography is 20 pixels on desktop, with the original reading measure and a blurred backdrop. Project and management documents retain the interface font. Desktop share controls form a compact icon rail; mobile keeps an expandable control. Inline contained outlines collapse to leave room for the document.
- Image loading previews no longer tile in the empty margins around expanded portrait images. Previews scale to their container and clear after the real image loads; lightbox margins use the viewing surface. Covered dialogs hide their close-control cluster while the foreground dialog is active, preventing competing controls on mobile.
- The window picker again groups entry and widget icons. Window controls float below the content, with drag, resize, maximize, restore, and viewport fitting accounting for their overhang. Closing windows and dialogs waits for their finite CSS exit animations instead of removing the surface immediately. Reduced-motion preferences still apply.

## External-system effects

`Masonry` observes its rendered width with ResizeObserver. It reads the column size and gap from the stylesheet, distributes items across that number of columns, and disconnects on unmount. It does not change image metadata or persisted content.

The window layer listens to viewport resizing and fits floating controls back into reach. Its cleanup removes that listener. Dragging, resizing, and keyboard movement still use the existing gesture and geometry engine. `exitSurface` observes only animations on the dismissing root, waits for completion or cancellation, then removes the instance; it does not wait on animated descendant scenes and uses no dismissal timer.

The request proxy supplies a validated route identity derived from the actual request pathname. Root rendering uses that identity and the render cookie's saved built-in route selections. SchemeHost updates those cookie fields when route choices change. This avoids showing the previously visited route's theme before hydration. Custom profile source remains in browser storage and paints after restoration; private profile data is not placed in the cookie.

## Verification and limits

`tools/perf/site-fidelity-smoke.mjs` checks server and hydrated route identities, font resolution, desktop project and album composition, reading type and blur, translucent modal paint, close-control placement, focus restoration through a nested real-content lightbox, completed close transitions, floating window controls, mobile overflow, and paused authored artwork. It requires the isolated migrated corpus, including NoTeX and A Garden's Tale. Its captures and reports are private local evidence under ignored work directories.

Live original comparisons included Home and its menu, Blog and A Garden's Tale, Projects and its hover/NoTeX reader, Photos, About, Design, Notebook, and Management. Captures use real uploaded v11 content. Image decoding must finish before judging media screenshots; a loading placeholder is not evidence that a migrated asset is missing.

The production build, both TypeScript trees, lint (zero errors, ten existing image warnings), all 1,512 tests in 92 files, spelling, directive placement, code-comment ban, layer usage, CSS syntax, generated assets, theme equivalence, and production output traces pass. The production browser checks cover nine route identities at desktop size and five mobile routes. The renderer lease check passes with one context; the three-second drag and navbar scroll checks at 4× CPU pass without sampled React commits or storage writes during movement, with one geometry write after release.

This review is evidence for these routes and shared defects, not a claim that every scene, palette, browser, or device has completed the specification's full visual matrix. Safari/Firefox, manual accessibility checks, and the exhaustive matrix remain release checks. No frontend deployment or existing bucket-content replacement is part of this restoration.
